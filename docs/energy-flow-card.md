# ZOTAC Energy Flow Card

Картка Home Assistant для гібридних інверторів (перевірено на Deye SUN-6K), яка **правильно показує потоки енергії, коли працює генератор**: генератор, мережа й сонце це джерела, а дім і АКБ споживачі. Потоки завжди йдуть у правильний бік: джерела → інвертор → дім/АКБ.

## Можливості

- Блоки: **Генератор, Мережа, Сонце (необовʼязково), Інвертор, Дім, АКБ**.
- Центр схеми це інвертор зі шкалою, яка ділиться за часткою кожного джерела. Колір активного джерела підсвічує шапку, рамку й потоки.
- Плавні анімовані потоки: швидкість залежить від навантаження, без смикань при зміні потужності.
- Стан **«Світла немає»**: червоний блок мережі, червона «пігулка» в шапці, рамка картки. Визначається за напругою мережі.
- Підпис **«до розряду / до повного»** з часом. Є власний розрахунок до заданого відсотка АКБ (наприклад, «до 15%»).
- Нижній ряд додаткових показників: струм, температури, вольти й ампери АКБ тощо. Перегрів підсвічується.
- **Візуальний редактор** налаштувань прямо в панелі HA (без YAML).
- На шкалі АКБ риска **межі розряду** (`battery_min_soc`) і межі заряду, колір шкали за рівнем: зелений, жовтий (<50%), червоний (<20% або біля межі).
- Неактивні джерела притемнені, активний шлях виділяється. Одиниці W/kW не миготять біля 1000 Вт.
- Захист від старих даних: якщо сенсор недоступний або давно не оновлювався, картка показує «Немає даних» і не малює потоки. Окремі сенсори без даних показують «—».
- Адаптивна: окремий компактний режим для ПК, центрування на телефоні, опційно розтягування на весь екран.
- Шрифт вбудований у файл, нічого не потрібно завантажувати з інтернету. Усі іконки свої (SVG), `mdi` не потрібен.
- Один файл, без залежностей, постачається разом з інтеграцією.

## Вимоги

- Home Assistant 2024.7 і новіше (рекомендовано вигляд **Секції**).
- Сенсори потужності вашого інвертора в HA (наприклад, інтеграція Deye).
- Мінімум один сенсор: навантаження дому. Решта необовʼязкова.

## Встановлення

Картка входить в інтеграцію **Deye EW11** і підключається автоматично: файл копіювати й ресурс додавати не потрібно.

1. Встановіть або оновіть інтеграцію через HACS до версії **2.2.0+** і перезапустіть HA.
2. Оновіть сторінку без кешу:
   - Mac: `Cmd + Shift + R`. Windows/Linux: `Ctrl + F5`.
   - Застосунок HA на телефоні: Налаштування застосунку → Companion App → Налагодження → **Reset frontend cache**, потім повністю закрийте й відкрийте застосунок.
3. Додайте картку. **Через інтерфейс:** режим «Змінити» → **Додати картку** → знайдіть **ZOTAC Energy Flow** (або «Ручна» і вставте YAML з прикладу нижче). Далі клацніть на картку, щоб відкрити візуальний редактор.

> Якщо раніше ви підключали картку вручну (`/local/zotac-energy-flow-card.js` у **Ресурсах**), видаліть той ресурс і файл з `/config/www/`, інакше може завантажитись стара копія.

## Мінімальний приклад

```yaml
type: custom:zotac-energy-flow-card
entities:
  load: sensor.deye_sun_6k_load_power
  battery: sensor.deye_sun_6k_battery_power
  soc: sensor.deye_sun_6k_battery_soc
```

## Повний приклад (Deye SUN-6K)

```yaml
type: custom:zotac-energy-flow-card
entities:
  load: sensor.deye_sun_6k_load_power
  battery: sensor.deye_sun_6k_battery_power
  soc: sensor.deye_sun_6k_battery_soc
  battery_runtime: sensor.deye_sun_6k_battery_runtime
  grid: sensor.deye_sun_6k_grid_power
  grid_voltage: sensor.deye_sun_6k_grid_voltage
  grid_frequency: sensor.deye_sun_6k_grid_frequency
  generator: sensor.deye_sun_6k_generator_power
  generator_status: sensor.deye_sun_6k_generator_status
  pv: sensor.deye_sun_6k_pv_power
  inverter_temp: sensor.deye_sun_6k_dc_temperature
battery_capacity_kwh: 16
battery_min_soc: 15
hide_when_zero:
  - pv
extras:
  - name: Струм AC
    entity: sensor.deye_sun_6k_inverter_current
    unit: A
  - name: DC Temp
    entity: sensor.deye_sun_6k_dc_temperature
    unit: °C
    warn_above: 55
  - name: AC Temp
    entity: sensor.deye_sun_6k_ac_temperature
    unit: °C
    warn_above: 55
  - name: АКБ вольти
    entity: sensor.deye_sun_6k_battery_voltage
    unit: V
    decimals: 2
  - name: АКБ ампери
    entity: sensor.deye_sun_6k_battery_current
    unit: A
  - name: АКБ Temp
    entity: sensor.deye_sun_6k_battery_temp
    unit: °C
    warn_above: 45
grid_options:
  columns: full
```

## Параметри

### Сенсори (`entities`)

| Ключ | Опис |
|---|---|
| `load` | Потужність навантаження дому, Вт. **Обовʼязковий** |
| `battery` | Потужність АКБ, Вт. Знак за замовчуванням: мінус = заряд, плюс = розряд |
| `soc` | Заряд АКБ, % |
| `battery_runtime` | Сенсор часу роботи/заряду АКБ (текст або число) |
| `grid` | Потужність мережі, Вт. Плюс = імпорт, мінус = віддача |
| `grid_voltage` | Напруга мережі, В. **Визначає стан «Світла немає»** (напруга ≤ 50 В) |
| `grid_frequency` | Частота мережі, Гц (показується в підписі блоку «Мережа») |
| `generator` | Потужність генератора, Вт |
| `generator_status` | Статус генератора (Running/Stopped тощо, перекладається автоматично) |
| `pv` | Потужність сонця, Вт. Необовʼязково |
| `inverter_temp` | Температура інвертора, показується в центрі схеми |
| `home` | Окремий сенсор для блоку «Дім» (за замовчуванням береться `load`) |

### Параметри картки

| Параметр | За замовч. | Опис |
|---|---|---|
| `title` | – | Заголовок над схемою |
| `battery_capacity_kwh` | – | Ємність АКБ, кВт·год. Потрібна для власного розрахунку часу |
| `battery_min_soc` | 0 | Рахувати час розряду до цього %, напр. 15. Підпис змінюється на «до 15%» |
| `battery_max_soc` | 100 | Рахувати час заряду до цього % |
| `max_power` | 6000 | Потужність, при якій потік біжить найшвидше (шкала швидкості), Вт |
| `min_power` | 10 | Поріг, нижче якого потік вважається вимкненим, Вт |
| `inverter_temp_warn` | 55 | Температура інвертора, вище якої число стає помаранчевим |
| `inverter_temp_decimals` | 1 | Знаків після коми у температурі в центрі схеми (0 = цілі) |
| `battery_marks` | true | Риски меж (`battery_min_soc`/`battery_max_soc`) на шкалі АКБ. `false` ховає їх, розрахунок часу лишається |
| `battery_level_colors` | true | Колір шкали АКБ за рівнем: жовтий до 50%, червоний до 20%. `false` = завжди зелена |
| `stale_minutes` | 5 | Через скільки хвилин без оновлення сенсора `load` дані вважаються застарілими (0 = вимкнути) |
| `flow_style` | `comet` | Вигляд потоків: `comet`, `dots`, `dash`, `wave`, `arrows`, `none` (див. розділ «Потоки енергії») |
| `flow_fps` | 30 | Кадрів/с руху потоків (5–60). Менше значення = менше навантаження на відеокарту. `0` = плавна анімація на кожен кадр монітора (навантажує GPU найбільше) |
| `flow_speed` | 1 | Множник швидкості потоків (0,5 повільніше, 2 швидше) |
| `animations` | `[]` | Додаткові анімації (список, див. розділ «Анімації») |
| `show_bus` | true | Показувати смужку в центрі інвертора. `false` ховає її |
| `bus_mode` | `sources` | Режим смужки: `sources` (джерела, як раніше), `load` (завантаження інвертора), `split` (звідки / куди), `temp` (температура) |
| `bus_cycle` | false | Клік по смужці перемикає режими по колу, вибір запамʼятовується в браузері |
| `bus_label` | false | Число під смужкою: загальна потужність (`sources`, `split`) або % завантаження (`load`) |
| `inverter_power` | 6000 | Номінальна потужність інвертора, Вт. Для режиму `load` (зелений до 60%, жовтий до 85%, червоний вище) |
| `bypass_current_a` | – | Струм байпаса, А (напр. 40). Коли живлення йде від мережі або генератора, режим `load` рахує завантаження від `струм × напруга` (напр. 40 А × 230 В = 9,2 кВт), а не від `inverter_power`. Порожньо = не враховувати |
| `bypass_badge` | `inverter` | Значок **bypass**, коли живлення йде від мережі/генератора (потрібен `bypass_current_a`): `inverter` (на блоці інвертора), `header` (у шапці з мінішкалою завантаження, напр. «2,3 / 9,2 kW»), `both`, `off` |
| `bypass_voltage` | – | Напруга для розрахунку байпаса, В. Порожньо: береться поточна напруга мережі (`grid_voltage`), якщо вона недоступна, 230 В |
| `show_inverter_temp` | true | Температура під смужкою. `false` ховає її |
| `battery_invert` | false | Інвертувати знак потужності АКБ |
| `grid_invert` | false | Інвертувати знак потужності мережі |
| `hide_when_zero` | `[pv]` | Які блоки ховати при нулі: `pv`, `generator`, `grid` |
| `names` | – | Власні назви: `pv`, `generator`, `grid`, `battery`, `home` |
| `extras` | – | Список плиток нижнього ряду (див. нижче) |
| `mobile_center` | true | На телефоні центрувати картку по вертикалі |
| `mobile_fill` | false | На телефоні розтягнути картку на весь екран по висоті |
| `mobile_offset` | 190 (центр) / 200 (на весь екран) | Відступ під шапку HA, px |

### Додаткові показники (`extras`)

| Поле | Опис |
|---|---|
| `entity` | Сенсор (обовʼязково) |
| `name` | Підпис |
| `unit` | Одиниця (за замовч. беться з сенсора) |
| `decimals` | Знаків після коми (за замовч. 1) |
| `warn_above` | Значення, вище якого число стає помаранчевим |

## Смужка інвертора

Вертикальна смужка в центрі має чотири режими (`bus_mode`):

- **`sources`**: висота ділиться за часткою джерел (як було раніше).
- **`load`**: заливка знизу вгору, потужність відносно `inverter_power`. Колір: зелений, жовтий, червоний.
- **`split`**: дві колонки, ліва «звідки» (джерела), права «куди» (дім, заряд АКБ, віддача в мережу).
- **`temp`**: шкала 20–80 °C з білою рискою на `inverter_temp_warn`.

```yaml
bus_mode: load
bus_cycle: true     # клік по смужці перемикає режим
bus_label: true     # число під смужкою
# show_bus: false   # сховати смужку повністю
# show_inverter_temp: false   # сховати температуру
```

## Потоки енергії

Вигляд потоків задає `flow_style`:

| Значення | Вигляд |
|---|---|
| `comet` | Комета з хвостом (як раніше, за замовчуванням) |
| `dots` | Світні крапки |
| `dash` | Пунктир, що біжить |
| `wave` | М'яка світлова хвиля |
| `arrows` | Стрілки в напрямку потоку |
| `none` | Без руху, лише підсвічена лінія |

Швидкість у всіх стилях залежить від навантаження, множник `flow_speed` змінює її загалом.

```yaml
flow_style: arrows
flow_speed: 1.2
```

## Анімації

За замовчуванням додаткові анімації вимкнені. Увімкніть потрібні списком `animations` (або у редакторі, розділ «Анімації»):

| Значення | Що робить |
|---|---|
| `breathe` | Підсвітка активних блоків повільно «дихає» |
| `icons` | Іконки активних блоків м'яко пульсують |
| `bus` | По смужці інвертора (режим `sources`) біжить світловий відблиск |
| `battery` | Край заповненої частини шкали АКБ блимає: швидко при заряді, повільно при розряді |
| `numbers` | Числа змінюються плавно, а не стрибком (при зміні одиниць W/kW стрибок лишається) |
| `enter` | Блоки по черзі зʼявляються при завантаженні картки |

```yaml
animations:
  - breathe
  - numbers
  - battery
```

Якщо в системі чи браузері увімкнено «Зменшити рух», ці анімації не запускаються.

## Візуальний редактор

Клацніть на картку в режимі «Змінити»: відкриється форма з розділами «Датчики», «Параметри», «Додаткові показники», «Телефон», «Назви блоків». Зміни зберігаються одразу. Перейти до YAML можна через ⋮ → «Показати редактор коду».

> Це вікно відкривається при кліку **на картку**, а не на секцію. Вікно «Edit section» налаштовує лише ширину й тему секції.

## Ширина на ПК

У вигляді **Секції** ширина залежить від налаштувань вигляду, а не картки:

```yaml
- type: sections
  max_columns: 2        # скільки колонок максимум
  sections:
    - type: grid
      column_span: 2    # скільки колонок займає секція
      cards:
        - type: custom:zotac-energy-flow-card
          grid_options:
            columns: full
```

Менша ширина: `1`, ширша: `3`. Також ширину секції можна задати в діалозі «Edit section» (повзунок «Ширина»).

## Як працює логіка

- **Заголовок і колір** визначає головне джерело: генератор, мережа, сонце, АКБ. Якщо є кілька, береться найпотужніше.
- **«Світла немає»** вмикається, коли напруга мережі ≤ 50 В (потрібен `grid_voltage`). Без цього сенсора стан визначається за наявністю потоку з мережі.
- **Потоки** бігають тільки там, де потужність вище `min_power`. Напрямок для АКБ і мережі береться зі знаку сенсорів.
- **Час до розряду/заряду** береться з `battery_runtime`. Якщо там порожньо, або задано `battery_min_soc`/`battery_max_soc`, картка рахує сама: `(Δ% × ємність) ÷ поточна потужність`. Це оцінка без урахування втрат і змін навантаження.
- **Натискання** на блок відкриває стандартне вікно історії сенсора.

## Вирішення проблем

| Проблема | Що робити |
|---|---|
| «Custom element doesn't exist» | Інтеграція Deye EW11 не встановлена або не налаштована, чи кеш. Перезапустіть HA й оновіть сторінку з Ctrl/Cmd+Shift+R |
| Нова версія не зʼявилась | Скиньте кеш браузера/застосунку. Перевірте, що в **Ресурсах** не лишився старий `/local/zotac-energy-flow-card.js` |
| Перевірити, що файл завантажується | Відкрийте `http://IP-HA:8123/deye_ew11/zotac-energy-flow-card.js`, має показатись код, а не 404 |
| АКБ показує розряд замість заряду | Додайте `battery_invert: true` |
| Мережа показує віддачу замість імпорту | Додайте `grid_invert: true` |
| «Світла немає» не вмикається | Вкажіть `grid_voltage` (сенсор напруги мережі) |
| Немає часу до розряду | Вкажіть `battery_runtime` або `battery_capacity_kwh` |
| Візуального редактора немає | Завантажена стара версія файлу. Скиньте кеш (див. вище) |
| Картка занадто вузька на ПК | Збільште `max_columns` і `column_span` секції (див. «Ширина на ПК») |
| Картка на телефоні не по центру | Змініть `mobile_offset` (більше число піднімає картку вище) |

## Оновлення

Картка оновлюється разом з інтеграцією через HACS. Після оновлення перезапустіть HA і скиньте кеш браузера/застосунку.
